# 位运算公式&性质速查

> 
> 约定：二进制**最低位为第0位**；位运算对内存中**补码**运算。

## 一、有符号数 / 无符号数

1. **有符号 signed**
最高位是符号位：`0正，1负`

- 正数：原码 = 反码 = 补码
- 负数：
  - 原码：数值转二进制，符号位置1
  - 反码：原码符号位不变，其余位按位取反
  - 补码：反码 $(+1)$
  - 补码求原码：取反 $(+1)$

2. **无符号 unsigned**
没有符号位，全部bit都是数值位；原码=反码=补码。
3. 右移区别

- signed：**算术右移**，右侧丢弃，左侧补符号位
- unsigned：**逻辑右移**，右侧丢弃，左侧补0

> 
> ⚠️ 移位不能移负数位数，属于C++未定义行为。

## 二、基础位运算符

| 运算符 | 名称 | 运算规则 |
| --- | --- | --- |
| `<<` | 左移 | 整体左移k位，左边丢弃，右边补0；等价 $\times 2^k$ |
| `>>` | 右移 | 整体右移k位；signed补符号位，unsigned补0 |
| `&` | 按位与 | 对应位**全1得1，否则0** |
| `\|` | 按位或 | 对应位**有1得1，全0得0** |
| `^` | 按位异或 | 对应位**相同0，不同1** |
| `~` | 按位取反（单目） | 所有bit：0↔1，操作补码 |

异或性质

1. $x \oplus x = 0$
2. $0 \oplus x = x$
3. 满足交换律、结合律

## 三、常用位运算公式（核心）

> 
> $i$ 代表目标二进制位的下标（从0开始）

1. **取出x的第i位**

```
int bit = (x >> i) & 1;
```

2. **把x第i位置1，其余位不变**

```
x |= (1 << i);
```

3. **把x第i位置0，其余位不变**

```
x &= ~(1 << i);
```

4. **翻转x第i位（0变1，1变0）**

```
x ^= (1 << i);
```

5. **Brian Kernighan：清除x最右侧的1**

```
x = x & (x - 1);
```

用途：循环统计二进制中1的个数。

6. **只保留x最右侧的1，其余全部置0**

```
int lowbit = x & -x;
```

7. 判断是否是2的幂

```
bool ispow2 = (x > 0) && ((x & -x) == x);
// 等价 (x>0) && ((x & (x-1)) == 0)
```

## 四、状态压缩相关公式

- `1 << i`：生成只有第i位为1的掩码
- `mask & (1 << i)`：判断mask的第i位是否为1
- `mask | (1 << i)`：mask的第i位置1
- `mask & ~(1 << i)`：mask的第i位置0
- `mask ^ (1 << i)`：mask的第i位翻转
- `__builtin_popcount(mask)`：GCC内置，统计mask中1的bit数量

### 极简代码片段示例

```
#include <iostream>
using namespace std;
int main()
{
    int x = 12; // 1100
    int i = 2;
    int bit = (x >> i) & 1;        // 取第2位
    x |= (1 << 1);                 // 第1位置1
    x &= ~(1 << 3);                // 第3位置0
    x ^= (1 << 0);                 // 第0位翻转
    int clearRight1 = x & (x - 1); // 抹掉最右侧1
    int lowbit = x & -x;           // 保留最右侧1
    cout << bit << " " << clearRight1 << " " << lowbit << endl;
    return 0;
}
```

## 五、优先级重要提醒

> 
> 位运算符优先级低于算术、关系运算符；做比较必须加括号。

```
// 错误
if(x & 1 == 1);
// 正确
if( (x & 1) == 1 );
```

## 六、小总结

1. 负数全部以**补码**参与位运算。
2. `~`得到的是补码结果，不是原码直接取反。
3. lowbit：`x & -x`；消除最右1：`x & (x‑1)`。
4. 移位负数位 → 未定义行为，禁止写。
