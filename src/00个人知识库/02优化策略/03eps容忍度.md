在算法竞赛和日常开发中，只要遇到**浮点数（`float` / `double`）**，并且涉及到**大小比较、相等判断**，或者**数学运算（如 `sqrt`, `sin`, `cos`, 除法）**，就**必须**用到 `1e-6`（通常被称为 `eps`，即误差容忍度）。

下面我给你梳理清楚它的**用处**、**使用时机**和**具体怎么用**。

---

### 一、 用处是什么？
**核心用处：消除计算机二进制存储小数时产生的微小误差，防止程序做出“错误判断”。**

计算机底层是用二进制存小数的。比如十进制的 `0.1`，在二进制里是一个无限循环小数。计算机只能截断它，这就导致了误差：
```cpp
double a = 0.1 + 0.2;
double b = 0.3;
if (a == b) { 
    // 这里绝对不会执行，因为实际上 a 是 0.30000000000000004，b 是 0.29999999999999999
}
```
`1e-6` 的作用，就是允许这两个数**在这个微小的范围内**被认为是相等的。

---

### 二、 什么时机使用？（四大常见场景）

#### 1. 判断两个浮点数“相等”
绝对不能写 `if (a == b)`。必须写成：
```cpp
if (fabs(a - b) < 1e-6) {
    // 认为 a 和 b 相等
}
```
*(注：`fabs` 是求浮点数绝对值的函数，需要 `#include <cmath>`)*

#### 2. 判断浮点数“大于”或“小于”
就像你刚才做的那道雷达题：
```cpp
// 错误写法：直接比大小，容易被微小的误差骗过去
if (a > b) 

// 正确写法：a 必须实打实地比 b 大，才能叫大
if (a > b + 1e-6)  // a 大于 b
if (a < b - 1e-6)  // a 小于 b
```

#### 3. 涉及几何计算（勾股定理、三角函数、斜率）
只要你代码里出现了 `sqrt()`, `asin()`, `cos()` 等数学函数，结果必带误差。这时候无论是求交点、算距离还是比大小，全都要加上 `eps`。

#### 4. 实数域上的“二分查找”（二分答案）
如果题目要求“求最大半径”、“求最短时间”，并且答案是小数，你的二分终止条件通常是这样写的：
```cpp
while (r - l > 1e-6) { // 当左右边界的差距小于 1e-6 时，认为已经足够精确，停止二分
    double mid = (l + r) / 2;
    // ...
}
```

---

### 三、 怎么用？标准模板代码

通常，老手会在代码最上面定义一个全局常量：
```cpp
const double eps = 1e-6; // 或者 1e-8，看题目要求的精度
```
然后用宏定义或者函数封装起来。

**最经典的四个比较函数（背下来）：**

```cpp
#include <cmath>

const double eps = 1e-8;

// 判断相等 (等于)
bool isEqual(double a, double b) {
    return fabs(a - b) < eps;
}

// 判断大于 (a 真的比 b 大)
bool isGreater(double a, double b) {
    return a > b + eps;
}

// 判断小于 (a 真的比 b 小)
bool isLess(double a, double b) {
    return a < b - eps;
}

// 比较大小（用于 sort 排序）
bool cmp(double a, double b) {
    if (isEqual(a, b)) return false; // 相等时，不交换
    return a < b; // 否则小的在前
}
```

---

### 四、 补充：`1e-6` 和 `1e-8` 怎么选？
*   **`1e-6` (0.000001)**：最常用的默认值。大多数题目（比如你刚才那道雷达题）用这个就足够了。
*   **`1e-8` (0.00000001)**：要求更高精度的题目。精度设得太小（比如 `1e-12`），有时会因为误差累积导致死循环或者判断失灵。
*   **题目要求**：有些题目会明确写出“**保留两位小数**”或“**误差不超过 \(10^{-5}\)**”，这时候你的 `eps` 只要比题目要求的小一个数量级就行了（如果要求 \(10^{-5}\)，你就用 `1e-6`）。

### 💡 一句话总结
**“看到 `double`，想到 `eps`；不拿小数直接比，加减 `1e-6` 最保险。”** 这句话是无数人踩坑后总结出来的血泪教训，以后做题遇到小数，条件反射加上 `eps` 就对了！
