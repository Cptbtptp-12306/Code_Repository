## 哈希本质

- **哈希是一套「把任意数据，通过哈希函数，压缩成一个有限范围整数」的映射方案；基于这套映射实现的查找结构叫做哈希表（散列表）**

1. **哈希函数**：只是一个转换函数 \(h(key)\)
2. **哈希表（散列表 Hash Table）**：数据结构，利用哈希函数实现快速增删查

## 哈希函数要求

给定输入 `key`，输出一个整数（哈希值），满足三条基本性质：

1. **确定性**：同一个 key，永远算出同一个哈希值
2. **计算速度快**，尽量只是乘、加、取模
3. **均匀分布**：不同的 key 尽量分散到不同哈希值，减少冲突

- 常用哈希函数
**`k(key) = key mod P`**，P一般选大质数（100003、10000003等）

示例：
P = 7
h(10) = 10 mod 7 = 3
h(17) = 17 mod 7 = 3

👉 这里 `10` 和 `17` 得到相同哈希值：**哈希冲突！**

> 
> 不同 key，哈希值相同，就是冲突。冲突是哈希与生俱来的问题，无法彻底避免，只能降低概率、做好处理

- 其他哈希函数

1. 多项式哈希（字符串哈希专用）：H = H * Base + s[i]，Base 常用 131、13331
2. 自然溢出哈希：`unsigned long long`，利用无符号数溢出自动对 2 ^ 64 取模，不用手动写 mod

> 
> ❗ 重点：哈希函数只负责算编号，**不负责存数据**，存数据是哈希表的工作

## 处理哈希冲突

### 方案 1：链地址法（拉链法，unordered_map 底层方案）

思路：

1. 开一个数组 `bucket[]`，数组里每个位置是一条链表（C++ 常用`vector<pair<key,val>>`）
2. 计算 pos = h(key)
3. 数据挂到 `bucket[pos]` 这条链表上
4. 查询：算出 pos，遍历这条链表比对原始 key，找到目标

`bucket[0] → []`

`bucket[1] → [(10, pos1的数据), (17, pos1的数据)]`

`bucket[2] → []`


优点：实现简单、删除方便、不容易集群堆积

❌ 缺点：冲突多的时候链表变长，性能退化到 O(n)

手写拉链哈希，就是竞赛用来卡 unordered_map 的常用模板

### 方案 2：开放寻址法

没有链表，全部数据塞在桶数组里。冲突了就往后找下一个空位存放。

- 线性探测：冲突 pos，依次试 pos+1, pos+2, pos+3 …
- 二次探测：偏移量用平方，避免扎堆

✅ 优点：连续内存，缓存友好

❌ 缺点：删除麻烦、容易 “聚集”，竞赛用得比拉链少很多

## 哈希容器

底层：链地址法哈希表

### 1. unordered_map<KeyType, ValType>

存键值对：key → value

`unordered_map<long long, int> last;`

`last[123456789] = 3;`

超级大坑：`if(last[x])`

如果 x 不存在，这行代码**会自动插入 x，value 初始化为 0**，直接污染哈希表！

✅ 正确判断是否存在：`last.count(x)`，返回 1 存在，0 不存在。

### 2. unordered_set<Type>

只存 key，没有 value，专门用来判重：某个元素有没有出现过

```
unordered_set<int> st;
st.insert(5);
if(st.count(5))

```

和 map（红黑树）对比:

unordered_map, 哈希表, 无序, 平均O(1)

map, 红黑平衡树, 按 key, 有序, 稳定O(logn)

## 哈希表与字符串哈希

### ① 哈希表（散列表）

用途：**增、删、查、判重，记录映射关系**
代表题目：UVA11572 唯一的雪花，两数之和

### ② 字符串哈希（前缀多项式哈希）

用途：**快速比较两个子串是否相等**，不关心存不存在，只关心内容是否相同

公式：

基数 Base，前缀哈希数组 H，幂数组 P

H[i] = H[i-1] * Base + s[i]

P[0] = 1, P[i] = P[i - 1] * Base

子串 s[l ～ r]的哈希值：

hash(l, r) = H[r] - H[l - 1] P[r - l + 1]

两种写法：

1. **自然溢出哈希**：`unsigned long long`，溢出自动取模 2 ^ 64，代码最短。缺点：有被卡单哈希的风险。
2. **双哈希**：两组不同 Base、不同模数，算出一对哈希值 pair<h1,h2>，冲突概率几乎可以忽略，比赛稳妥写法。

> 
> 字符串哈希本质是：给每个子串算出一个指纹，指纹相同大概率内容相同。
> 注意：指纹相同 ≠ 一定相同，只是概率极低。

``` cpp
#include <iostream>
#include <vector>
using namespace std;
typedef long long ll;

const int MOD = 100003; // 大质数模数
vector<pair<ll, int>> bucket[MOD];

// 哈希函数，保证负数取模结果为正
int get_pos(ll key)
{
    int res = (key % MOD + MOD) % MOD;
    return res;
}

// 查询key，存在返回对应value；不存在返回0
int find(ll key)
{
    int pos = get_pos(key);
    for(auto &pr : bucket[pos])
    {
        if(pr.first == key)
            return pr.second;
    }
    return 0;
}

// 插入/更新 key -> val
void insert(ll key, int val)
{
    int pos = get_pos(key);
    // 先查找，如果已经存在就更新
    for(auto &pr : bucket[pos])
    {
        if(pr.first == key)
        {
            pr.second = val;
            return;
        }
    }
    bucket[pos].emplace_back(key, val);
}

int main()
{
    insert(123456789, 5);
    cout << find(123456789) << endl;
    return 0;
}
```
