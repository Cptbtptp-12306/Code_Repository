## 哨兵的本质

- 哨兵（sentinel）本质：**人为在数组的边界位置放一个不可能成为答案的 “假元素”**，用来**省去边界条件 if 判断**，简化代码

> 原来：拿到 pos 之后，要先判断 `pos == 1` 的时候不能访问 `pos-1`，否则越界、拿到垃圾值。
> 加哨兵之后：就算 `pos=1`，`pos-1` 是哨兵；哨兵和 x 的差值巨大，`min` 会自动抛弃它，不用写 if。

⚠️ 核心前提：哨兵的值要离题目合法值域足够远，**哨兵和任何查询值的差值，一定大于所有合法差值**，保证它永远不会被选为最小值

## 使用时机

- 闭区间 `r=m`：pos 最大 m，只会访问 pos-1 → **只用左哨兵**
- 左闭右开 `r=m+1`：pos 最大 m+1，pos 和 pos-1 都可能越界 → **左右双哨兵**

## 如何使用

### ✅ 适用场景

**有序数组二分查找，拿到 pos 之后，需要同时比较 pos 和 pos-1（或者 pos 和 pos+1）两个相邻元素求最值**
典型题目：

1. P1678 烦恼的高考志愿（找离 x 最近的数）⭐就是这道
2. 找大于等于 x 和小于等于 x 的数做差值

> 
> 不适合：单纯找数、统计数量的二分题（A-B 数对、区间查找，没必要）

### ✅ 使用步骤（左哨兵单哨兵版，你这套）

1. 数组开的空间预留 a [0] 的位置（下标从 1 开始）
2. 数组排序之后，给 `a[0]` 赋值一个**离合法值域很远的值**
3. 二分用闭区间模板 `l=1,r=m`
4. 直接 `min( abs(a[l]-x), abs(a[l-1]-x) )`，不用 if 判断

### ✅ 使用步骤（左右双哨兵版，左闭右开模板）

1. 数组开大一点，预留 a [0] 和 a [m+1]
2. 排序后：`a[0] = -INF; a[m+1] = INF;`
3. 二分 `l=1, r=m+1`
4. 直接 `min( abs(a[l]-x), abs(a[l-1]-x) )`

### ⚠️ 哨兵的雷区（一定要记）

1. 哨兵值不能离合法范围太近！比如本题值域 0~1e6，哨兵写 `-1e5` 就有概率翻车，要 `-1e7`
2. **哨兵模板不能随便混用**：闭区间只用左哨兵；左闭右开才需要双哨兵；模板和哨兵不匹配直接越界 WA
3. 如果题目值域有负数，哨兵要拉得更远，不能想当然写 - 1e5
4. 哨兵是**简化代码的技巧，不是标准解法**，写不稳就换回 if 判断版本
