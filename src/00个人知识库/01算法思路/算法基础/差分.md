# 模板

## 一维差分

- 创建差分数组

`f[i] = a[i] - a[i - 1]`

`f[i] += a[i], f[i + 1] -= a[i]`

- 根据差分数组性质处理q区间

`f[L] += c, f[R + 1] -= c`

当[L, R]区间内每个a[i]都+c，则L与L - 1差值+c，R + 1与R差值-c

- 前缀和还原原数组

f[1] = a[1]; a[1] = f[1]

f[2] = a[2] - a[1]; a[2] = a[2] − a[1] + a[1] = f[2] + f[1]

f[3] = a[3] − a[2]; a[3] = a[3] − a[2] + a[2] − a[1] + a[1] = f[3] + f[2] + f[1]

***f[i] = a[i] − a[i − 1]; a[i] = f[i] + f[i − 1] + f[i − 2] + ... + f[1]***

## 二维差分

- 解法思路

先根据差分矩阵的【性质】创建差分矩阵，然后根据差分矩阵的性质处理q次区间修改，最后利用【前缀和】还原原始的矩阵

1.在差分数组中某个位置标记：表⽰后续元素统⼀被修改

2.在差分数组中求前缀和：能够还原出原始数组

假设：我们需要将原始矩阵a中，以为(x1, y1)左上⻆,(x2, y2)为右下⻆的⼦矩阵的每个元素都加k

**二维差分求前缀和会把右下角全部元素都加k**

- 性质

1.f[x1][y1] += k

2.f[x2][y2 + 1] -= k

3.f[x2 + 1][y1] -= k

4.f[x2 + 1][y2 + 1] += k
