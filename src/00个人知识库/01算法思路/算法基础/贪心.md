# 推公式 + 排序

推公式就是寻找排序规则，排序就是在该排序规则下对整个对象排序，在解决某些问题的时，当我们发现最终结果需要调整每个对象的先后顺序，也就是对整个对象排序时，那么我们就可以⽤推公式的⽅式，得出我们的排序规则，进⽽对整个对象排序

>正确性证明：
 1. 利⽤排序解决问题，昀重要的就是需要证明"在新的排序规则下，整个集合可以排序"。这需要⽤到离散数学中"全序关系"的知识。我会在第⼀道题中证明该题的排序规则下，整个集合是可以排序的。
 2. 但是证明过程很⿇烦，后续题⽬中我们只要发现该题最终结果需要排序，并且交换相邻两个元素的时候，对其余元素不会产⽣影响，那么我们就可以推导出排序的规则，然后直接去排序，就不去证明了

# 哈夫曼编码

## 1. 核心概念

哈夫曼编码是一种**前缀编码**，任意一个字符的编码都不会是另一个字符编码的前缀，解码时不会产生歧义。
它的目标：根据字符出现频次，给高频字符分配短编码、低频字符分配长编码，让整个字符串编码后的总长度最小。
总长度 = 带权路径长度（WPL），也就是这道题要求的值。

> 
> WPL定义：每个叶子节点的权值（字符出现次数） × 该叶子到根节点的路径长度（编码位数），全部相加。

## 2. 哈夫曼树构造规则（贪心）

1. 把所有字符频次当成独立叶子节点，放到小根堆里；
2. 每次取出堆里**权值最小的两个节点**；
3. 新建一个父节点，权值 = 两个节点权值之和；
4. 这个父节点的权值累加进答案（WPL），再把父节点放回堆；
5. 重复上面操作，直到堆里只剩下一个节点。

> 
> 原理：频次小的节点会被多次合并，路径更长；频次大的节点少合并，路径更短，刚好符合“高频短码”。

## 3. 样例推演

输入：

```
3
1 2 3
```

节点初始：`1，2，3`

- 第一轮：取出1、2，合并得到3，答案 +=3（ans=3），堆变为 `3，3`
- 第二轮：取出3、3，合并得到6，答案 +=6（ans=9），堆只剩6，结束
输出：9，和样例一致。
编码方案：频次1→00，频次2→01，频次3→1
WPL = 1×2 + 2×2 + 3×1 = 2+4+3 = 9

## 4. 代码逻辑说明

```
#include <iostream>
#include <queue>
using namespace std;
typedef long long LL;
int main()
{
    int n;
    cin >> n;
    priority_queue<LL, vector<LL>, greater<LL>> heap; // 小根堆
    for(int i = 1; i <= n; i++)
    {
        LL x; cin >> x;
        heap.push(x);
    }
    LL ans = 0;
    while(heap.size() > 1)
    {
        LL a = heap.top(); heap.pop();
        LL b = heap.top(); heap.pop();
        LL sum = a + b;
        ans += sum;
        heap.push(sum);
    }
    cout << ans << endl;
    return 0;
}
```

- `greater<LL>`：构建小根堆，堆顶永远是最小值；
- 必须用`long long`：ai最大可以到10^9，累加极易溢出int；
- 边界：`n=1`，只有一种字符，不需要合并，WPL=0。

## 5. 贪心证明（简要）

贪心选择性：最优哈夫曼树中，频次最小的两个节点一定是兄弟节点。
所以每次合并最小两个节点，一定能构造出全局最优解，满足贪心选择性质。

## 6. 时间复杂度

一共n个元素，堆操作是O(log n)，总复杂度 O(nlog n)，可以通过 2 * 10^5 的数据范围。

# 区间问题

## 贪心区间四大基础模型 + 防晒霜拓展模型（纯文字，可直接复制）
贪心区间题统一底层逻辑：**优先处理限制最严格、选择空间最小的区间，避免它后面没有资源可用；排序是贪心的核心，排序方式决定策略。**

### 模型1：活动选择（最多选出互不重叠的区间，洛谷P1803 凌乱的yyy）

题目描述：给定若干区间，选出尽可能多的区间，任意两个区间不能重叠。
贪心策略：将所有区间**按照右端点从小到大排序**。

执行流程：

1. 排序之后，第一个区间直接选；
2. 记录上一次选中区间的右端点last；
3. 依次往后遍历，如果当前区间的左端点 ≥ last，说明不冲突，选择这个区间，更新last为当前区间右端点；
4. 直到遍历结束，统计选中总数。

思想解释：

选结束最早的区间，能最快释放后面的空间。如果选一个结束晚的区间，会挤占后面大量区间的机会。右端点越早，留给后续的可选空间越大，才能选出最多数量。

贪心证明思路：

贪心选择性：一定存在最优解包含右端点最小的区间。假设最优解没有选它，把最优解里第一个区间替换成这个最早结束的，不会减少答案。

最优子结构：选定当前区间之后，剩下的问题就是在这个右端点之后，继续选最多不重叠区间，子问题独立。

### 模型2：区间点覆盖（最少放置点，让每个区间内至少包含一个点）

题目描述：给定一堆区间，放最少数量的点，使得每一个区间里面都至少有一个点。

贪心策略：区间**按右端点从小到大排序**。

执行流程：
1. 排序；
2. 初始化last = -无穷；
3. 遍历区间：如果当前区间左端点 > last，说明这个区间没有被之前的点覆盖；在**当前区间的右端点**放一个点，更新last；

思想解释：

把点放在区间最靠右的位置，这个点可以同时覆盖尽可能多和它重叠的后续区间。如果放在靠左位置，很容易漏掉后面重叠的区间，需要新增更多点。一句话：一个点发挥最大覆盖能力。

### 模型3：区间分组（最少分成多少组，同一组内区间互不重叠）

题目描述：给定若干区间，分组，每组里面的区间不能重叠，求最少分组数目。

贪心策略：区间**按左端点从小到大排序**；用小根堆维护每一组最后一个区间的右端点。

执行流程：

1. 排序；
2. 依次遍历每个区间；
3. 看堆顶（所有组里面最早结束的那一组的右端点）：
   - 如果当前区间左端点 ≥ 堆顶：可以接在这一组后面，弹出堆顶，把当前区间右端点放进堆；
   - 如果当前区间左端点 < 堆顶：所有组都还没结束，不能插入任何已有组，新开一组，把当前右端点入堆；
4. 堆内元素个数就是最少分组数。

思想解释：

我们优先复用最早空闲的组，而不是盲目新开组。小根堆帮我们快速找到最先结束的组。本质：尽可能复用已有资源，减少新增组数。

补充结论：最少分组数 = 同一时间重叠区间的最大数量。

### 模型4：区间覆盖（用最少数量区间，覆盖一条指定的大线段 [S,T]）

题目描述：目标是覆盖从起点S到终点T的整条线段，给很多小区间，挑选最少的小区间完成全覆盖。

贪心策略：区间**按左端点从小到大排序**。

执行流程：

1. 排序；
2. 记录当前已经覆盖到的位置now；目标终点T；
3. 在所有左端点 ≤ now 的区间里面，找到右端点最远的那一个；
4. 选中这个区间，把now更新为这个最远右端点；
5. 重复，直到now≥T；如果找不到可以延伸的区间，说明无法覆盖。

思想解释：

在满足可以接上当前覆盖边界的前提下，一步尽可能往远处延伸。每一次选择都最大化推进覆盖距离，以此减少选取区间的个数。
坑点：不能按右端点排序，必须保证区间起点能接上前面已经覆盖的部分。

### 拓展模型：区间分配资源（防晒霜P2887，给区间分配带数量限制的点）

题目描述：每个区间（奶牛）需要分配一个落在区间内的点（防晒霜spf），每种点有使用次数上限，求最多能匹配多少区间。

贪心策略：区间（奶牛）按右端点从小到大排序；点（防晒霜）按数值从小到大排序。

执行流程：
1. 奶牛按右端升序，防晒霜spf升序；
2. 逐个处理奶牛，从头扫描防晒霜，找到第一个在区间内、还有余量的防晒霜分配；
3. 优化版（大数据）：单向指针+小根堆，把spf≤奶牛右端点的防晒霜全部入堆，堆顶是最小spf，优先分配最小合法spf。

思想解释：

右端点小的奶牛，可选spf范围很小，限制最苛刻，如果不优先分配，很容易被别的奶牛抢走合适的防晒霜，最后它无药可用。优先救选择范围窄的；把数值更大的spf留给右端更大、可选范围更广的奶牛。

## 统一总结（做题判断）

1. 目标：最多不重叠区间 / 最少点覆盖区间 → 右端点升序
2. 目标：最少分组 → 左端点升序 + 小根堆维护组尾
3. 目标：最少区间覆盖长线段 → 左端点升序，每次选能伸最远的
4. 目标：区间分配有限资源（点）→ 区间右端升序，优先给窄区间分配资源
