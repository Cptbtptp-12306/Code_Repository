# 用户及其管理权限

## 用户管理机制

<details>

<summary> 📂 Linux 用户分类（点击展开） </summary>

### 1. 管理员用户：uid=0，用户名 root

- 特点：系统最高权限账号，可以掌控系统一切资源
- 查看命令：`id root`

`[root@node1 ~]# id root`
`uid=0(root) gid=0(root) 组=0(root)`

> ⚠️ root 权限无限制，操作风险极高，一旦误删文件会直接破坏系统

- 发行版区别：
  - Ubuntu 默认禁用 root 登录，使用 sudo 机制提权
  - CentOS 默认允许 root 登录，但生产环境强烈不建议直接用 root 操作

### 2. 系统用户：uid 1~999

- 用途：**给后台服务程序本身使用，不是给真人登录用的**
- 例子：nginx、mysql、www 这类服务账号，进程启动时以这个用户身份运行
- 好处：服务进程权限被限制，就算服务被入侵，也拿不到 root 权限，安全隔离

> 
> 后台运行的服务进程在用，不是人类登录

### 3. 普通用户：uid 1000~60000

- 创建者：root 管理员创建
- 使用者：真实登录的人类用户
- 默认限制：权限受限，不能随便改系统核心文件，需要的时候用`sudo`临时拿管理员权限

> 
> 普通用户通过 sudo 机制，临时借用管理员权限执行管理操作

</details>

<summary> 📂 Linux 用户分类 </summary>

### 1. `useradd` 创建普通用户

**语法：`useradd 用户名`**
示例：

`useradd qwe`
`useradd asd`

> 默认行为：
> 
> 
> 1. 自动创建同名**主组**（qwe 组、asd 组）
> 2. 自动创建家目录 `/home/qwe`、`/home/asd`
> 3. 默认不会自动设置密码，新建用户后无法登录

> 
> 补充参数：
> `-g` 指定主组；`-G` 指定附加组；`-M` 不创建家目录

### 2. `passwd` 设置用户密码

**语法：`passwd 用户名`**
示例：

`passwd qwe`

- root 可以给任意用户设置密码
- 普通用户不加用户名，代表修改自己的密码

> 
> ⚠️ 输入密码时终端不回显，看不见光标跳动，正常现象

### 3. `groupadd` 创建用户组

**语法：`groupadd 组名`**
示例：

`groupadd developers`

新建一个名叫`developers`的用户组，用来统一管理一批用户权限

### 4. `usermod` 修改用户所属组（重点！）

**语法：`usermod -aG 附加组 用户名`**
示例：

`usermod -aG developers qwe`
`usermod -aG developers asd`

- `-G`：设置附加组；**不加 `-a` 会覆盖掉用户原来所有附加组，高危！**
- `-a` = append，追加，保留原有附加组，只新增

### 配套查看命令

- `id 用户名`：查看 uid、gid、所有所属组
- `cat /etc/passwd`：查看所有用户信息
- `cat /etc/group`：查看所有用户组信息

<summary>📂 文件权限表示（ll / ls -l）（点击展开）</summary>

### 1. 权限字符串拆解：`-rwxrwx---`

第一位：**文件类型**

- `-`：普通文件
- `d`：目录（文件夹）
- `l`：软链接
- `b/c`：块设备、字符设备

后面 9 位，分成 3 组，每组 3 位：`属主u | 属组g | 其他o`
每组内顺序固定：**r 读、w 写、x 执行**

- `r` read：可读，值 = 4
- `w` write：可写，值 = 2
- `x` execute：可执行 / 进入目录，值 = 1
- `-`：无对应权限，值 = 0

示例拆解：`-rwxrwx---`

- 第 1 组（属主 u）：`rwx` → 4+2+1=7
- 第 2 组（属组 g）：`rwx` → 4+2+1=7
- 第 3 组（其他 o）：`---` → 0+0+0=0
数字权限等价：`770`

> 
> ✅ 重要区分：x 对**文件**= 运行程序；x 对**目录**=cd 进入这个目录

## 2. `ll`（ls -l）一整行字段含义

`drwx------ 4 asd asd 112 9月 27 23:55 asd`

左到右依次：

1. `drwx------`：文件类型 + 9 位权限
2. `4`：硬链接计数
3. `asd`：文件**属主（拥有者）**
4. `asd`：文件**属组**
5. `112`：文件大小（目录这里是目录项大小，不是里面文件总大小）
6. `9月 27 23:55`：最后修改时间
7. `asd`：文件名

示例：
`drwxrwsr-x 4 root developers 28 9月 27 23:56 share_data`

- 文件类型：d（目录）
- 属主 root：rwx
- 属组 developers：rws（s 是 SGID 特殊权限，组继承）
- 其他人：r-x

`-rw-r--r-- 1 root root 15 9月 28 00:22 test.txt`

- 文件类型：-（普通文件）
- 属主 root：rw-
- 属组 root：r--
- 其他人：r--
数字权限等价：`644`

### 3. chmod 修改权限（配套命令）

两种写法：符号写法 / 数字写法

`chmod 755 test.sh`
`chmod u+x test.sh`

- u：属主，g：属组，o：其他人，a：全部
- `+` 增加权限，`-` 去掉权限，`=` 设置权限

### 4. chown 修改属主、属组

`chown qwe test.txt`
`chown qwe:developers test.txt`
