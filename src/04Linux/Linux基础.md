# Linux基础

## 文件操作

- 1.`cp` （copy，复制）

**语法：`cp 源文件 目标位置`**

- 示例 1：`cp a.txt b.txt` 把 a.txt 复制一份，新文件叫 b.txt，两个文件互相独立，修改一个不影响另一个
- 示例 2：`cp a.txt ./test/` 把 a.txt 复制到 test 文件夹里
- 复制目录一般加 `-r`：`cp -r dir1 dir2`（递归复制文件夹）

> 
> 默认 cp：生成**独立副本**，占用双倍磁盘空间

- 2.`rm` （remove，删除）

**语法：`rm 文件`**

- `rm a.txt`：删除 a.txt
- 删除文件夹（非空目录）：`rm -r dir`；`rm -rf dir` 强制删除，**高危！谨慎使用，没有回收站**

> 
> ⚠️ Linux rm 删除后很难恢复

- 3.`mv`（move，移动 / 重命名）

两种用法：

1. **移动文件**：`mv a.txt ./test/`，把 a.txt 挪到 test 目录，原位置文件消失（不是复制！）
2. **改名**：`mv old.txt new.txt`，同一个目录下 mv，等价重命名

> 
> mv 本质：修改目录项，**不拷贝磁盘数据，速度极快**

- 4.`touch`

**作用：创建空白新文件；如果文件已存在，则更新文件的时间戳**

- `touch hello.c`：新建一个空的 hello.c

> 
> ❗touch**不能创建文件夹**，建文件夹是`mkdir`
