设要切成的⻓度为x，能切成的段数为c。根据题意，我们可以发现如下性质:

- 当x增⼤的时候，c在减⼩。也就是最终要切成的⻓度越⼤，能切的段数越少
- 当x减小的时候，c在增大。也就是最终要切成的⻓度越小，能切的段数越多
- 当x <= res时，c >= k。也就是「要切的⻓度」⼩于等于「最优⻓度」的时候，最终切出来的段
数「⼤于等于」k
- 当x > res时，c < k。也就是「要切的⻓度」⼤于「最优⻓度」的时候，最终切出来的段数「⼩于」k

**在解空间中，根据res的位置，可以将解集分成两部分，具有「⼆段性」，那么我们就可以「⼆分答案」**

- 遍历整个数组，针对每⼀根⽊头，能切成的段数就是a[i]/x
