# 最大子段和（Kadane算法）

## 贪心选择性

贪心策略：遍历数组，维护当前连续段和 sum。

1. 若 sum ≥ 0：当前段对后续数字有正向贡献，继续向后累加；
2. 若 sum < 0：当前段对后续数字没有正向贡献，直接舍弃这一段，将累加和重置为0，从下一个数字重新开始。
同时全程记录遍历过程中出现过的最大区间和。

证明（反证法）：
假设存在一段区间 [a,b]，满足 sum[a,b]<0。我们想要证明：在 [a,b] 里面不存在一个点 c(a<c≤b)，使得从 c 出发的连续子段，会比从 a 出发更优，舍弃 [a,b] 是安全的，不会漏掉最优解。分两种情况讨论：

1. 子段向右延伸，终点超过 b：
如果存在 c，使得 sum[c,b] > sum[a,b]，可以推出 sum[a,c-1]<0。按照贪心策略，当累加走到 c-1 的位置时，累加和已经小于0，会在 c 之前就重置起点，不会一直累加到 b，矛盾。因此不存在这样的 c。
2. 子段终点在 b 左侧（不超过 b）：
如果存在 c 和 k(b≥k≥c)，使得 sum[c,k] > sum[a,k]，同样推出 sum[a,c-1]<0，贪心策略会在 c 之前舍弃 [a,c-1]，矛盾。

综上，一段总和小于0的区间，区间内部没有任何一个起点，能比直接抛弃整段、从后面重新开始更好。我们的贪心选择（舍弃负和前缀）是合法的贪心选择，存在包含该贪心选择的全局最优解，满足贪心选择性。

补充说明：该策略是清零版Kadane，底层允许空段，使用时需要单独记录遍历中所有区间和的最大值，才能处理全负数的输入。

## 最优子结构

设 dp[i] 代表以第 i 个元素结尾的最大非空连续子段和。
以 i 结尾的子段只有两种可能：

1. 子段长度大于1：这个子段一定是以 i-1 结尾的最优子段，接上 a[i]；
2. 子段长度等于1：子段仅包含 a[i]。

转移方程：
dp[i]=max(a[i], dp[i-1]+a[i])
原问题的最优解，就是 max{dp[1],dp[2],…,dp[n]}。
原问题最优解，由子问题（以每个位置结尾的最大子段和）的最优解构成，满足最优子结构。

## 小结

- 贪心选择性：负和前缀对后面所有延伸都只有减益，直接舍弃不会丢失最优解；
- 最优子结构：以i结尾的最优段，依赖以i-1结尾的最优段，子问题最优可以推出全局最优。
