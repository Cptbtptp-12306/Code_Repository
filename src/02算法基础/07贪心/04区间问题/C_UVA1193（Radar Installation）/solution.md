# 区间选点问题：雷达安装 (UVA1193 / 洛谷变种) 解题笔记

## 1. 问题抽象：二维降一维
**题目大意**：在海岸线（x 轴）上放置最少的雷达，覆盖所有岛屿。雷达覆盖半径为 d。

**核心转化**：
对于任意一个岛屿 (x, y)，如果要在 x 轴上找一点 (X, 0) 能够覆盖它，必须满足距离公式：
(X - x)^2 + (0 - y)^2 <= d^2

解这个不等式，可以得出雷达 X 的合法放置区间：
[x - sqrt(d^2 - y^2), x + sqrt(d^2 - y^2)]

**结论**：问题从“二维平面上的圆覆盖”完美转化为**“一维数轴上的区间选点问题”**——用最少的点，使得每个区间内至少包含一个点。

## 2. 贪心策略推导

要让雷达数量最少，核心思想是**“让每个雷达尽可能覆盖更多的区间”**。

### 策略 A：按右端点排序（强推，最简洁）
1. 将所有区间按**右端点从小到大**排序。
2. 第一个雷达直接放在第一个区间的**右端点**（因为越靠右，越有可能“顺手”覆盖后面的区间）。
3. 遍历后续区间：如果当前区间的**左端点 > 雷达位置**，说明覆盖不到，必须新增一个雷达，并把新雷达放在当前区间的**右端点**。
4. **无需更新雷达位置**：因为按右端点排序，后面的区间右端点一定更大，雷达位置不会“缩水”。

### 策略 B：按左端点排序（容易踩坑）
1. 将所有区间按**左端点从小到大**排序。
2. 第一个雷达放在第一个区间的**右端点**。
3. 遍历后续区间：
   - 如果当前区间的**左端点 > 雷达位置**，说明覆盖不到，新增雷达，放在当前区间右端点。
   - **【隐藏陷阱】**如果左端点 <= 雷达位置（重叠），雷达可能落到了当前区间的右侧！必须更新雷达位置为：`r = min(雷达位置, 当前区间右端点)`。这叫“收缩阵地”，确保雷达能同时覆盖重叠的区间。

## 3. 代码避坑指南（踩坑血泪史）

1. **无解判断**：如果输入时发现岛屿纵坐标 y > d，说明无论雷达怎么放都够不到，直接标记无解，输出 -1。
2. **浮点数精度误差（核心大坑）**：
   - 计算 sqrt(d^2 - y^2) 时会产生微小的浮点误差。
   - **绝不能用 `if (a[i].l > r)` 直接比大小！** 必须在雷达位置加上容忍度 eps（如 1e-6），改为 `if (a[i].l > r + 1e-6)`，防止错判成“覆盖不到”导致多算雷达。
3. **多组数据处理**：注意 `while(cin >> n >> d, n && d)` 的写法，以及 `Case X:` 的输出格式。
