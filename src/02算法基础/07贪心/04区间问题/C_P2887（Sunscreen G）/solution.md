# 思路
本题是区间选点类贪心问题，目标是给每头奶牛分配一个落在它区间[l,r]内的防晒霜，求最多能分配多少头奶牛。
贪心策略：优先选择右端点更小的奶牛，这类奶牛可选范围更小，如果不优先分配，很容易出现没有防晒霜可用的情况；防晒霜按照spf从小到大排序，优先给奶牛分配满足条件的最小spf防晒霜，把更大的spf留给区间右边界更大的奶牛。

1. 排序：将所有奶牛按照区间右端点升序排序；防晒霜按照spf数值升序排序。
2. 遍历每一头奶牛：从头依次扫描防晒霜，跳过已经用完、或者spf小于奶牛区间左端点的防晒霜；如果遇到spf大于奶牛区间右端点，因为防晒霜有序，后面spf只会更大，直接停止本轮扫描。
3. 找到第一个符合区间要求、还有余量的防晒霜，使用一瓶，计数加一。
4. 全部奶牛遍历完成后，输出总数量。

大数据版本（优先队列）思路：
1. 排序：奶牛按右端点升序，防晒霜按spf升序。
2. 使用一个指针单向遍历防晒霜，对于当前奶牛，把所有spf不超过这头奶牛右端点的防晒霜全部加入小根堆，指针只向前移动，不回退。
3. 小根堆堆顶是当前最小spf，不断弹出堆顶：如果spf大于等于奶牛左端点，则分配成功，答案+1；如果spf小于奶牛左端点，说明这个spf对之后所有奶牛都无效，直接丢弃。
4. 遍历完所有奶牛，输出答案。该做法时间复杂度$O(n\log n)$，适合十万级大规模数据。
